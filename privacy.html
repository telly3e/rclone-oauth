Privacy Policy

Last updated: November 19, 2026

Rclone Personal Drive Sync is a private OAuth 2.0 application operated solely by its owner for personal use with rclone.

1. Data Collection and Usage

This application does not collect, track, store, or process personal data from any third-party users. It only requests Google Drive API access for the owner's own Google account in order to read, write, and synchronize files via rclone.

2. Data Storage and Security

OAuth access and refresh tokens are stored exclusively on the owner's private local devices or VPS inside the rclone configuration file. No tokens or Google Drive contents are transmitted to any external or third-party servers other than Google's official APIs.

3. Data Sharing

No user data or Google Drive data is ever sold, shared, or disclosed to third parties.

4. Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
