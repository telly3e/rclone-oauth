Rclone Personal Drive Sync

Personal OAuth 2.0 Client for Google Drive & Rclone

This application is a private, self-hosted OAuth 2.0 client created solely for personal file synchronization and backup between the owner's personal servers and their own Google Drive account using rclone.

Purpose

  • Authenticate personal rclone CLI instances to access the owner's Google Drive.
  • Perform encrypted backups, file transfers, and directory synchronization.
  • Not intended for public distribution or multi-user commercial use.
